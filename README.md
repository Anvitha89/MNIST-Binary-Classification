# MNIST Binary Classification Using SGDClassifier

## Project Overview
This project uses the MNIST handwritten digit dataset to classify whether an image represents digit 5 or any other digit.

## Technologies Used
- Python
- NumPy
- scikit-learn
- Jupyter Notebook

## Model
SGDClassifier

## Evaluation Metrics
The model was evaluated using:
- Confusion Matrix
- Accuracy
- Precision
- Recall
- F1-score

## Test Results
- Accuracy: 95.82%
- Precision: 94.38%
- Recall: 56.50%
- F1-score: 70.69%

## Conclusion
The model achieves high overall accuracy and precision but has lower recall, meaning it misses some actual digit-5 images. Improving recall is a potential next step.
